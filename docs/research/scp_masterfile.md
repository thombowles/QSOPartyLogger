# MASTER.SCP — super check partial database

**Source:** `https://www.supercheckpartial.com/MASTER.SCP` — the Super
Check Partial project's distribution site. Observed 2026-08-04.

## Server behavior (what `SCPClient` is built against)

- Valid TLS via BunnyCDN — plain HTTPS, no ATS exception needed.
- HEAD answers with `Last-Modified: Fri, 31 Jul 2026 00:03:08 GMT`,
  `Content-Length: 359507`, and an `ETag`. `Last-Modified`'s date equals
  the file's own `# Release 2026.07.31` stamp, so a HEAD can judge
  freshness without the body — the cty.dat situation exactly.
- `Cache-Control: public, max-age=21600` — a CDN in front of a file that
  changes every few weeks.

## File shape (fetched 2026-08-04, release 2026.07.31)

    !!Order,1,1
    #
    # Super Check Partial
    # Release 2026.07.31
    # Generated by bb-scp
    #
    2D0OMN
    2E0AOZ
    …
    ZZ7ZZ

- 50,027 lines, CRLF-terminated; 50,020 calls after the directive and
  comments.
- Calls are uppercase `[A-Z0-9/]`, three characters or longer.
- The `!!Order,1,1` directive and `#` comments are the only non-call
  lines; `SCPDatabase.parse` drops anything that does not scan as a call,
  so neither needs a special case.

## Standing

**Hint data, never authority** (constitution Article 1): the file is a
community distillation of submitted contest logs. Nothing from it reaches
scoring, validation, or export — it draws the strip of known calls under
the entry row, and that is all.

The file is deliberately not bundled (the call history precedent):
`SCPClient` downloads it on first launch and re-checks daily by HEAD,
so the season never starts on a committed copy that has aged.
