         2026 MS QSO PARTY RULES

Starts: 1400z / 4 April 2026
Ends: 0200z / 5 April 2026
Duration: 12 Hours

Objectives:
  - Maximize the activation of MS amateur radio stations in as many counties possible.
  - Encourage amateurs around the world to contact as many MS stations as possible.
  - Incorporate FT4/8 digital modes into the event.

Bands: 160m, 80m, 40m, 20m, 15m, 10m, 6m, 2m

Modes: CW, SSB, RTTY, FT4/8

Contacts: Same station can be worked on each separate band/mode.
Example, W5XX can work W1AW on 20m CW, 20m SSB, 20m RTTY, 20m FT4/8.

Exchange:
   - W/VE stations send signal report and State or Province.
   - DX stations send signal report and Country.
   - MS stations send signal report and County.
   - ALL FT4/8 stations send signal report and Grid Square.

QSO Points: SSB = 1; CW = 2; RTTY = 2; FT4/8 = 2

Multipliers: (Earned ONCE regardless of band/mode worked.)
  - W/VE stations earn 1 for each MS County worked in SSB/CW/RTTY (82 possible) + 1
      for each MS Grid Square worked in FT8/4 (9 possible...EM41-44 and EM50-54).
  - DX stations earn 1 for each MS County worked in SSB/CW/RTTY (82 possible) + 1 for
      each MS Grid Square worked in FT8/4 (9 possible...EM41-44 and EM50-54).
  - MS stations earn 1 for each MS County worked (82 possible), 1 for each of the remaining
      States worked (49 possible), 1 for each Canadian Province/Territory worked (13
      possible), 1 for each remaining DX Country/Entity worked (336 possible) in
      SSB/CW/RTTY, then taking the total number of Grid Squares worked in FT8/4 and
      dividing by 4. Example: 100 Grid Squares worked, divided by 4, equals 25 multipliers.
      (Round up to nearest whole number.)

Scoring:
   - Fixed: Final score equals the sum of QSO points multiplied by the total multipliers.
   - Portable/Mobile: Final score will be the sum of the scores from each County operated.
   - Vicksburg ARC Contest Committee decisions are final.
   -   To aid scoring please use the scoring summary spreadsheet located under the MSQP tab
       on www.arrlmiss.org. Note that there are different tabs in the spreadsheet for W/VE, DX
       and Mississippi based stations.

Entry Categories: (No separate mode or power categories)
   - Single Operator Fixed
   - Single Operator Portable
   - Single Operator Mobile With Driver
   - Single Operator Mobile Without Driver
   - Unlimited Operators/Transceivers Fixed
   - Unlimited Operators/Transceivers Portable
   - Unlimited Operators/Transceivers Mobile

Miscellaneous:
   - All operators must observe the limits of their operator licenses.
   - An operator may use only one callsign during the QSO Party.
   - Households with multiple amateurs may share the same station.
   - QSO-finding assistance (e.g., monitoring DX clusters) is allowed.
   - Self-spotting or asking to be spotted is allowed by mobile/portable MS stations ONLY.
   - MS County abbreviations for CW operators can be found on www.arrlmiss.org
   - For exchange/logging purposes MSQP uses the standard Canadian Province/Territory
       abbreviations found at
       https://en.wikipedia.org/wiki/Provinces_and_territories_of_Canada

Software/Log Submission:
   - Use commercial software when possible (i.e., N1MM+, N3FJP, WSJT-X, JTDX, etc).
      Each of these produces a Cabrillo log listing QSO data.
   - Hand-written legible logs will be accepted.
   - Each submission should include a separate scoring summary showing the number of
      QSOs/Points/Multipliers/Final Score claimed. A scoring summary sheet can be found on
      www.arrrlmiss.org.
   - Deadline submission to Vicksburg ARC is 30 April 2026.
   - E-mail entries to W5XX at ARRL.NET; Snail-mail entries to W5XX callbook address.

Awards:
Certificates will be awarded to the highest scoring:
   - Each MS County (minimum 50 QSOs).
   - Each State/Province/Country (minimum 10 QSOs).
   - Any station making 100+ QSOs.
Plaques will be awarded to the highest scoring:
   - MS Single Operator Fixed
   - MS Single Operator Portable
   - MS Single Operator Mobile With Driver
   - MS Single Operator Mobile Without Driver
   - MS Unlimited Operators/Transceivers Fixed
   - MS Unlimited Operators/Transceivers Portable
