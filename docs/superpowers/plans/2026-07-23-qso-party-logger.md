# QSO Party Logger Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Mac-native SwiftUI QSO Party logger with county-line expansion, per-party county validation, live scoring w/ bonuses, K3 CAT + DTR/RTS CW keying, ADIF/Cabrillo export.

**Architecture:** Document-based SwiftUI app (`ReferenceFileDocument`, `.qplog` JSON). Pure `Core` layer (models, JSON-driven party definitions, engines, exporters) with exhaustive unit tests; `Hardware` layer (POSIX serial, K3 driver with pure parse functions, thread-based CW keyer) tested via mocks/pure functions; thin `UI` layer. XcodeGen project, Swift 6, macOS 15+, sandbox + serial entitlements.

**Tech Stack:** Swift 6 / SwiftUI / XCTest / XcodeGen / IOKit + POSIX termios. No third-party dependencies.

**Execution mode:** Inline (executing-plans) — autonomous session, no reviewer available; verification = `xcodebuild test` green per task + final launch smoke test.

**Canonical data (already fetched, in scratchpad):** `KSQP-Mults.txt` (official 105 KS abbrs), `KSQPRules2026.txt` (official 2026 rules), `TX_county_abbrevs.txt` (official 254 TX abbrs). County JSON is **generated by script** from these files — never hand-typed.

Key contracts (used by every later task — do not drift):
```swift
enum Band: String, Codable, CaseIterable { case m160="160m", m80="80m", m40="40m", m20="20m", m15="15m", m10="10m", m6="6m", m2="2m"
  static func from(freqKHz: Int) -> Band?      // ham band edges
  var defaultFreqKHz: Int                       // Cabrillo fallback (3550, 7040, 14040, …)
  var adif: String }                            // "80m" etc.
enum ModeClass: String, Codable { case phone, cw, digital }
struct QSO: Identifiable, Codable, Hashable {
  var id: UUID; var groupID: UUID; var timestampUTC: Date
  var call: String; var band: Band; var modeClass: ModeClass
  var rawMode: String                           // ADIF mode: CW/SSB/RTTY/FT8…
  var freqKHz: Int?; var rstSent: String; var rstRcvd: String
  var myLoc: String; var theirLoc: String }     // county abbr or state/prov/DX
enum MyLocation: Codable, Equatable { case inState(counties: [String]); case outOfState(location: String)

struct StationProfile: Codable { callsign, name, email, address, city, stateProvince, postalCode, country, club, operators: String; categoryOperator/Power/Station/Transmitter/Mode enums w/ Cabrillo raw values }
struct ContestLog: Codable { schemaVersion=1, partyID: String, station: StationProfile, myLocation: MyLocation, qsos: [QSO] }
```
